# 🐶 Mini Cadastro Pet Shop

Projeto desenvolvido em **Java** durante as aulas da disciplina de **Paradigmas da Programação**, com o objetivo de praticar os conceitos de **Programação Orientada a Objetos (POO)**.

## 📖 Sobre o projeto

O sistema simula um cadastro simples de um Pet Shop, permitindo o gerenciamento de tutores, endereços, pets e atendimentos.

As informações são exibidas de forma encadeada:

**Atendimento → Pet → Tutor → Endereço**

---

## 🚀 Tecnologias utilizadas

- Java
- IntelliJ IDEA
- Programação Orientada a Objetos (POO)

---

## 📂 Estrutura do projeto

```
src/
│
├── Main.java
└── model/
    ├── EnderecoModel.java
    ├── TutorModel.java
    ├── PetModel.java
    └── AtendimentoModel.java
```

---

## ✅ Funcionalidades

- Cadastro de tutores
- Cadastro de endereços
- Cadastro de pets
- Cadastro de atendimentos
- Validação de CPF
- Validação da UF
- Validação do peso do pet
- Validação do valor do atendimento
- Impressão dos dados de forma encadeada

---

## 🎯 Objetivos de aprendizagem

Durante o desenvolvimento deste projeto foram aplicados os seguintes conceitos:

- Classes e Objetos
- Encapsulamento
- Construtores
- Getters e Setters
- Composição entre classes
- Validação de dados
- Organização de código em pacotes
